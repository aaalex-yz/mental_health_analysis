# 🧠 Mental Health Lifestyle Analysis

This repository supports the final report for **IDS201: Introduction to Data Science** at Torrens University Australia (2025). It explores how lifestyle and demographic factors influence anxiety and depression scores using Python-based data analysis.

---

## 📎 Appendix Reference

This repository corresponds to **Appendix A** of the submitted report, which includes the complete source code, reproducible figures, and data preparation steps. It ensures methodological transparency for academic review and supports reproducibility of findings.

If citing or referencing this work for educational or research purposes, please credit the dataset creator (see below) and the author of the analysis.

---

## 📂 Project Structure

- `/data`: Contains the cleaned dataset.
- `/plots`: Visualizations generated during analysis.
- `analysis.py`: Full pipeline – preprocessing, EDA, regression, plotting.
- `requirements.txt`: Required packages and versions for reproducibility.

---

## 📊 Objective

Using regression and correlation analysis, the project identifies key predictors of depression, with a focus on how physical activity moderates sleep-related effects.

---

## 📈 Key Findings

- Physical activity significantly reduces depressive symptoms in poor sleepers.
- Young adults and non-binary participants showed elevated psychological vulnerability.
- Sleep quality and social support emerged as major protective factors.
